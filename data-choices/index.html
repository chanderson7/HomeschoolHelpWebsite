Data & account choices

Development version · Updated September 25, 2026. These controls are present in source revision bb8bb85. Production backend behavior still requires end-to-end verification.

Local files, portfolio photos, cloud snapshots, and your account are related but separate. Choose each action carefully.

Pause or resume automatic backup

For a signed-in account, automatic cloud backup is enabled by default. Open Settings → Manage Backups & Restore and turn Automatic Cloud Sync off to pause new automatic snapshots. Turning it off does not delete snapshots already stored. Use Sync Now to request an immediate snapshot when the setting is on.

Save and restore snapshots

Choose Save Snapshot Now for a manual copy. Refresh the list and select a snapshot to restore it. Restore replaces the local JSON school record for this account; it does not merge records and does not restore locally stored portfolio image files. The screen lists up to 20 recent snapshots, which is not a retention promise.

Export records

The Records area can generate PDF reports and transcripts, CSV files, calendar files, report cards, and reading records. Review names, grades, notes, signatures, and other learner information before sharing an export. Files shared outside the app are controlled by the destination you choose.

Sign out or reset a password

Settings → Sign Out ends app access on that device and clears the local session. It does not delete the account, school-record files, portfolio photos, or cloud snapshots. Use the login screen's password-reset flow if needed.

Erase device data

Settings → Data & Storage → Erase All Device Data resets locally stored school state. Portfolio images are stored as separate local files; verify the final release erases those files as intended before relying on this control. Deleting the app removes its local container, while offloading may preserve data. Apple device backups can have a separate lifecycle.

Delete an account

When signed in, open Settings → Manage Backups & Restore → Delete Account. The confirmation offers two choices: delete the cloud account and backups while keeping school records on this device, or also erase device school data. The app clears the local login session even if the server cannot confirm remote deletion, so a production error must be resolved before assuming cloud removal completed.

The checked-in database migration defines an authenticated account-deletion procedure, but this website has not verified its production deployment. There is no separate per-snapshot deletion button in the reviewed source.

Manage a Pro subscription

Use Manage Pro Subscription in Settings or the paywall to open Apple's subscription-management sheet. Canceling a subscription changes future entitlement and billing; it does not delete an account, local records, or cloud snapshots. Restore Purchases asks Apple to refresh eligible entitlements.

Access and correction

Use editing and deletion controls in learners, courses, lessons, records, reading, and portfolios to correct current local records. Local changes do not rewrite older snapshots. Read the Privacy Policy for data types, providers, and current retention limits, or visit Support.
