YOUR FAMILY'S INFORMATION MATTERS

Website privacy

Last updated September 21, 2026

Explore the idea without sharing your family's learning records.

This notice explains how the current HomeSchoolHelper preview website works, including its interactive demo, external resources, and public support links. It applies to this website only. HomeSchoolHelper is not yet a released iOS application.

At a glance

  • No website accounts, email signup, payment collection, or file uploads.
  • No analytics or advertising trackers are included in the website code.
  • Demo entries are temporary and reset when the prototype reloads.
  • Fonts and prototype libraries are requested from third-party services.
  • GitHub issues are public, so keep private family information out of support reports.

Information you enter

The website does not ask for names, email addresses, payment details, or educational records. There is no website database for visitor profiles or submitted schoolwork.

The interactive prototype includes editable sample fields, such as lesson setup and demo expenses. These illustrate a possible app experience. Use fictional information when trying them; do not enter children's real names, grades, medical information, financial details, or other private records.

How the prototype handles data

The prototype starts with fictional people and sample learning records. Supported changes, such as checking a lesson or adding a sample expense, are held in the page's temporary memory. They are not submitted to a HomeSchoolHelper backend or saved to a user account.

Reloading the prototype resets its demo state. There is no save, backup, restore, or real transcript export service. Some screens display fixed examples rather than values calculated from your entries.

The website does not use browser local storage or session storage to preserve demo entries. Temporary page state is not a secure place to keep real records, and the demo should not be used for actual school recordkeeping.

Technical information and hosting

When you visit a website, your browser sends technical information to the server delivering it. This can include an IP address, the requested page or file, request time, browser information, and a referring page where the browser permits it.

Any hosting provider may process or retain request logs to deliver pages, diagnose errors, or protect its service. The current project does not configure a public hosting provider or a log-retention period. When viewed through a local preview, the local web server may log page requests. This notice will need to reflect the selected provider before a public deployment.

Fonts and prototype libraries

The website loads its typography from Google Fonts, using requests to fonts.googleapis.com and fonts.gstatic.com. These requests can disclose standard connection information, including your IP address and browser information. The site uses fallback fonts if external fonts cannot load.

The prototype loads interface and icon libraries from unpkg.com. Requests for those files likewise disclose standard request information to that service. These resources help render the demo; the website does not intentionally send demo field values to these providers.

External providers operate under their own policies. You can read Google's Privacy Policy for information about Google's practices. HomeSchoolHelper does not control third-party processing or retention.

Cookies, analytics, and advertising

The current website code does not set cookies, use advertising pixels, run visitor analytics, or build advertising profiles. It does not sell demo entries or operate a personal-data sharing feature.

Your browser may cache pages, fonts, and scripts as part of normal browsing. Browser history and cached resources are distinct from saved demo records. Hosting services and external websites may have their own storage practices; this statement describes the code shipped with this preview website.

Public support and GitHub links

Project and support links lead to GitHub, a separate service. Simply following a link does not send your demo entries with it. If you sign in or post an issue there, GitHub processes that activity under its privacy statement.

Issues in the public project repository can be seen by other visitors. Your GitHub username, message, and any attached screenshots may be visible. Check screenshots for names, addresses, grades, browser tabs, or other personal information before posting.

For a privacy concern, begin with a general request through the support page without including sensitive details. A private contact channel is not currently listed. Do not post identity documents or children's records to establish a request.

Children's information

This preview is intended for parents and caregivers exploring a product concept. It has no child account registration and does not ask children to submit personal information. Names and educational examples included in the demo are fictional.

Parents and caregivers should use sample information during exploration and avoid putting identifying details about a child into either the demo or public support reports.

Retention and your choices

HomeSchoolHelper does not maintain a database of entries from this prototype. Reload the demo to discard its temporary state. You can clear your browser's history and cache through browser settings; this does not remove any logs held by hosting or external resource providers.

You can block external resource requests with browser controls or extensions. The website has fallback fonts, though some prototype icons or interface details may be unavailable. You can also read the feature descriptions without entering anything into the demo.

If you have posted information to GitHub, use GitHub's account, editing, and support controls to manage it. Removing a public post may not remove copies that others have already made. Provider-held information is subject to that provider's practices, not the prototype's reload behavior.

Security and limits

The embedded prototype runs in a restricted frame and does not have a HomeSchoolHelper account or record-storage backend. These design choices reduce what this preview needs to handle, but they are not a guarantee that sensitive information would be safe to enter.

Keep real educational records in a system intended for that purpose. This website does not provide secure document storage, recovery, or confidential messaging.

The future iOS app

Planned features such as local records, backups, exports, optional synchronization, and billing are not live website services. Their privacy and security arrangements have not been finalized.

App-specific privacy information will be provided when the application is available. This website notice should not be read as a promise about the app's eventual data collection, storage location, sharing, or retention.

Changes to this notice

This page will be updated if the website adds features that change its data practices, such as analytics, launch-update forms, or a support service. The date at the top identifies the latest revision. Review the updated notice before providing information through any new feature.

For project information and the current support route, visit Support.
