Website privacy

Last updated September 21, 2026

A simple product preview

This website introduces the HomeSchoolHelper concept. The website code does not include analytics, advertising trackers, signup forms, or cookies. It does not ask for your family's educational records.

The interactive prototype

The prototype uses fictional sample data. Changes you make stay in the page's temporary memory and reset when it reloads. It does not create an account or save your information to a database. The preview may load an icon library from unpkg.com; that provider can receive standard request information, including your IP address.

Fonts

The site requests fonts from Google Fonts. Google receives standard connection information, including your IP address and browser information, when your browser requests these fonts. System fonts are used if those requests fail.

Hosting and external links

The service hosting this website may process ordinary request information, such as IP addresses and browser details, under its own policies. Links to GitHub take you to a separate service governed by its privacy policy.

The future app

This notice describes the preview website, not a released iOS application. App-specific privacy information will be provided when the application is available.

For project questions, visit our support page.
