HOMESCHOOLHELPER · HELP & LEGAL

Support

Help for your homeschool day, account, records, and Pro membership.

HomeSchoolHelper is in development for iOS 17 and later. The browser prototype uses fictional temporary data and is not the native app.

Contact

The app lists support@homeschoolhelper.app and privacy@homeschoolhelper.app. These development addresses currently have no advertised MX mail route. Delivery and monitoring must be configured and tested before release.

Until a private channel is confirmed, use the public project links below only for general, non-sensitive issues. Include the app version, iOS version, device model, steps, and exact error text. Never post learner records, portfolio photos, passwords, reset links, or purchase receipts.

Signing in

The current release source requires a Supabase account before the workspace opens. Confirm your email if prompted and return through the app's authentication link. Use password reset on the login screen. If the app cannot verify the session, check connectivity and try again.

Planning and records

Add a learner, create courses and lesson sequences, and choose dated or flexible pacing. Use Records for attendance, activities, grades, report cards, transcripts, reading, portfolio items, and exports. Completion and attendance remain separate actions. Review state presets and every generated report against your own requirements.

Book scanning and portfolio photos

Barcode scanning requires a supported physical device and Camera permission. The app sends the scanned ISBN to Open Library for book details; you can enter details manually if lookup fails. Portfolio capture requires Camera or Photo Library access. Image files stay local in the reviewed code and are not restored with a cloud snapshot.

Cloud backup and restore

Open Settings → Manage Backups & Restore. Automatic Cloud Sync is on by default and can be paused. Use Sync Now or Save Snapshot Now for an immediate copy. Restore replaces local JSON records with the selected snapshot rather than merging changes. Keep local portfolio images and independent exports when they matter.

Subscriptions

The development StoreKit configuration offers monthly and annual Pro plans. Use Restore Purchases after reinstalling or changing devices. If Apple reports an active subscription, use Manage Pro Subscription in Settings. Billing, cancellation, refunds, price, and trial eligibility are handled through Apple.

Deletion and data safety

Read the Privacy Policy, Terms of Service, and Data & account choices. The source includes account deletion and local-device erasure, but production deletion must be verified. Do not uninstall as a first troubleshooting step because some records and all portfolio images may exist only on the device.

Public bug reports

General technical issues can be reported in the app repository or website repository. GitHub issues are public and may require an account.
